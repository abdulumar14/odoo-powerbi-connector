Power BI Connector for Odoo 18

Connect your Odoo data to Microsoft Power BI in minutes

🔒 Secure Token Authentication

Every Power BI request is authenticated with a secret token you generate from Odoo Settings. No username/password exposed.

⚡ Live & Scheduled Sync

Choose per dataset — live mode queries Odoo in real-time, scheduled mode caches data for fast Power BI refresh.

🗂️ Dynamic Dataset Manager

Add any Odoo model as a dataset from the UI — no coding needed. Supports custom fields created with Odoo Studio.

📊 8 Pre-built Datasets

Installed automatically: Purchase Orders, PO Lines, Vendor Bills, Customer Invoices, Stock Moves, Projects, Analytic Lines, Vendors.

Installation

  1. Install the module from Apps
  2. Go to Settings → Power BI → click Generate Token
  3. In Power BI Desktop → Get Data → Web → Advanced
  4. Enter URL: https://yoursite.com/powerbi/data/purchase_orders
  5. Add header: X-PowerBI-Token = your token
  6. Click OK — your data loads instantly
